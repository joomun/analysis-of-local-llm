How to read this dashboard

  • Live throughput panel: Shows real‑time token generation and prompt rates.
  • Stats grid: Avg generation/prompt speed, total tasks, tokens generated, model count, warnings/errors.
  • Bar charts: Token per second for each model (generation & prompt).
  • Model breakdown table: Per‑model metrics: tok/s, tasks, tokens, draft acceptance, load time, vision flag.
  • Sessions table: When each model session started, load time, context size, slots, threads, port.
  • Health & warnings panel: Recent errors and warnings from log parsing.
  • Data source section: Log root path, number of files, date range covered.
